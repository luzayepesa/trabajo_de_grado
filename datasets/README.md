# Datasets

**df_model_Aprob_Neg** contiene todos los datos de la convocatoria. La variable Resultado Final tiene tanto Aprobados como Negados
**df_model_final_Aprob** no tiene la variable Resultado Final debido a que aquí sólo se incluyen la información de postulntes con becas Aprobadas para poder determinar el porcentaje de beca aprobado y la probabilidad de que dada una beca, se matricule
